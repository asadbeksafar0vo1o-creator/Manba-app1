# Changelog

## 3.2 — Cinematic Orbit
- Added a lightweight Canvas 2D orbital background: animated stars, elliptical orbital paths, satellite silhouettes and occasional meteors.
- Added remote Blue Marble Earth texture and Moon texture with CSS gradient fallbacks.
- Refined the hero banner, typography, gradient action buttons, glass panels and responsive spacing.
- Improved sticky horizontal navigation for small screens and stronger desktop dashboard spacing.
- Preserved the existing study features and local-first storage behavior.
- Added reduced-motion handling and documented external texture/network dependencies.

- Free/Pro remains a local demo selector, not a payment system.
