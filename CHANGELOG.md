# O‘zgarishlar

## Manba — yangilangan versiya

- Sozlamalar bo‘limi va yuqorida tezkor sozlama tugmasi qo‘shildi.
- OpenRouter API kaliti kiritish, ko‘rsatish/yashirish, o‘chirish va ixtiyoriy ravishda shu qurilmada saqlash qo‘shildi.
- Cloudflare Worker URL va AI modelini ilova ichidan tanlash qo‘shildi.
- AI ulanishini sinash tugmasi qo‘shildi.
- Model tanlovi Worker ruxsat bergan model ro‘yxati bilan moslashtirildi.
- Worker uchun ixtiyoriy `ALLOWED_ORIGIN` va `APP_ORIGIN` sozlamalari qo‘shildi; CORS cheklovi autentifikatsiya emasligi hujjatlashtirildi.
- Keng so‘rovlarda kalit so‘z mos kelmasa, manba bo‘laklari bo‘yicha zaxira qidiruv qo‘shildi.
- Bir nechta PDF/DOCX faylni tanlash yoqildi.
- Lokal ma’lumotlarni o‘chirish, ma’lumotlar xulosasi, mobil tartib va vizual dizayn yangilandi.
- Service Worker keshi `v2` ga yangilandi.
- README qayta yozildi: ishga tushirish, AI ulash va kalit xavfsizligi ko‘rsatmalari.
